# Yıldız Souls — Mobil Proje

- `www/index.html` → oyunun kendisi (mobil için güvenlik ve dokunmatik ayarlı sürüm)
- `KURULUM.md` → iOS ve Android'e çıkış adımları (buradan başla)
- `GUVENLIK.md` → güvenlik incelemesi ve yapılan düzeltmeler
- `magaza/` → mağaza metinleri, ekran görüntüleri, tanıtım görseli, gizlilik politikası
- `web/` → iPhone'da ana ekrana eklenebilen, internetsiz çalışan web uygulaması sürümü (GitHub Pages ile yayınlanabilir)
- `KURULUM-IPHONE.md` → Mac olmadan TestFlight ve Android APK için bulut derleme
- `.github/workflows/android-apk.yml` → GitHub'da otomatik, imzalı APK derlemesi
- `assets/` → ikon ve açılış ekranı kaynakları
- `scripts/native-ayarlar.js` → yatay ekran, tam ekran ve güvenlik ayarlarını yerel projelere uygular

Hızlı başlangıç: `npm run kurulum`
